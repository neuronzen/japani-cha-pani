# জাপানি চা পানি — ওয়েবসাইট

চা, কফি, জুস ও ফাস্টফুডের দোকানের জন্য সম্পূর্ণ রেসপন্সিভ (মোবাইল-ফ্রেন্ডলি) ওয়েবসাইট।
পুরো সাইট **শুদ্ধ বাংলায়**, বাংলা ফন্টসহ, আর কোনো ইন্টারনেট/CDN ছাড়াই চলে।

---

## ১. সাইটে কী কী আছে?

| সেকশন | কী আছে |
|---|---|
| **হিরো** | বড় ব্যানার ছবি, দোকানের নাম, "মেনু দেখুন" ও "কল করুন" বাটন, রেটিং/ডেলিভারি টাইম |
| **বিশেষত্ব** | ফ্রেশ উপকরণ, ৫ মিনিটে সার্ভ, ডেলিভারি, পরিষ্কার রান্নাঘর — ৪টি কার্ড |
| **মেনু** | ৩০টি আইটেম, ৪টি ক্যাটাগরি (চা ৮ · কফি ৭ · জুস ও লাচ্ছি ৮ · ফাস্টফুড ৭) — প্রতিটি কার্ডে ছবি, দাম ও "+ যোগ করুন" বাটন |
| **কম্বো অফার** | ৩টি প্যাকেজ (সকালের ধামাকা / সন্ধ্যার সাথী / ফ্যামিলি বুন্দোবস্ত), সেভ-এর পরিমাণ লেখা |
| **আমাদের কথা** | দোকানের গল্প, ফিচার লিস্ট, ৩টি পরিসংখ্যান |
| **গ্যালারি** | ৫টি ছবির মোজাইক |
| **ক্রেতার রিভিউ** | ৩টি রিভিউ কার্ড |
| **যোগাযোগ + অর্ডার ফর্ম** | ঠিকানা, ফোন, সময়, পেমেন্ট, সোশ্যাল লিংক + অর্ডার ফর্ম |
| **ফুটার** | দ্রুত লিংক, ক্যাটাগরি লিংক, যোগাযোগ |

**অর্ডার সিস্টেম যেভাবে কাজ করে:**
1. ক্রেতা মেনুর যেকোনো আইটেমে "+ যোগ করুন" চাপে → নিচে ডান দিকে **"অর্ডার তালিকা"** বাটনে আইটেম জমা হয় (মোট দামও দেখায়)।
2. নাম, মোবাইল নম্বর (ভ্যালিডেশনসহ), ঠিকানা লিখে সাবমিট করলে লেখা অর্ডার নিয়ে **হোয়াটসঅ্যাপ মেসেজ তৈরি হয়** — ক্রেতা শুধু Send চাপলেই অর্ডার দোকানে পৌঁছে যায়।
3. তালিকা ব্রাউজারে (localStorage) সেভ থাকে, তাই ভুলে পেজ রিফ্রেশ হলেও হারায় না।

## ২. ফাইল স্ট্রাকচার

```
index.html              পুরো ওয়েবসাইটের কাঠামো ও সব লেখা (HTML)
styles.css              ডিজাইন: রঙ, ফন্ট, লেআউট (CSS)
script.js               অর্ডার তালিকা, ফিল্টার, ফর্ম, হোয়াটসঅ্যাপ (JavaScript)
assets/
  img/                  সাইটের সব ছবি (jpg = ফটো, svg = ভেক্টর আর্ট)
  fonts/                বাংলা ফন্ট (Noto Sans Bengali + Baloo Da 2) — অফলাইনেও চলবে
  raw/                  AI দিয়ে বানানো মূল ছবিগুলো (ক্লোজ-আপ/পোস্টারের জন্য)
  tools/make_art.py     ভেক্টর ছবিগুলো আবার তৈরি করার স্ক্রিপ্ট (দরকার হলে)
  preview/              সাইটের স্ক্রিনশট (ফেসবুকে শেয়ার করার জন্য ব্যবহার করতে পারেন)
README.md               এই ফাইল
```

## ৩. চালু করবেন কীভাবে

- **সহজ উপায়:** `index.html` ফাইলে ডাবল ক্লিক করুন — ব্রাউজারে সাইট খুলে যাবে।
- **লোকাল সার্ভার দিয়ে (রেকমেন্ডেড):** প্রজেক্ট ফোল্ডারে টার্মিনাল খুলে —
  ```bash
  python3 -m http.server 8000
  ```
  তারপর ব্রাউজারে `http://localhost:8000` খুলুন।

## ৪. নিজে যেভাবে বদলাবেন

### ক) ফোন নম্বর ও হোয়াটসঅ্যাপ (সবচেয়ে জরুরি)
1. **`script.js`** ফাইলের একদম উপরে:
   ```js
   var SHOP = {
     whatsapp: "8801711000000",   // ← আপনার হোয়াটসঅ্যাপ নম্বর (দেশের কোড ৮৮ সহ, + ছাড়া)
     currency: "৳"
   };
   ```
2. **`index.html`**-এ `টেলিফোন/হোয়াটসঅ্যাপ` লিংকগুলোও বদলান — সার্চ করুন `8801711000000` এবং `tel:+8801711000000`। (টপবার, হিরো, যোগাযোগ, ফুটার — মোট ৬–৭ জায়গা।)

### খ) দাম বা আইটেমের নাম বদলানো
`index.html`-এ Ctrl+F দিয়ে আইটেমের নাম লিখে খুঁজুন। প্রতিটি কার্ড এ রকম:
```html
<article class="dish" data-cat="tea" data-name="মালাই চা" data-price="30">
  ...
  <span class="price">৳ ৩০ <small>/ কাপ</small></span>
```
- `data-price="30"` → কার্টে হিসাবের জন্য **আরবি সংখ্যায়** লিখতে হবে।
- `৳ ৩০` → স্ক্রিনে দেখানোর জন্য **বাংলা সংখ্যায়** লিখুন (না লিখলেও চলবে)।
- `data-name` আর `data-price` — এই দুটো ঠিক রাখলেই বাকি কাজ স্ক্রিপ্ট নিজে করবে।

### গ) নতুন আইটেম যোগ করা
যেকোনো একটি `<article class="dish" ...> ... </article>` ব্লক কপি করে নিচে বসিয়ে নাম, দাম ও ছবি বদলে দিন। `data-cat` হবে `tea`, `coffee`, `juice` বা `fastfood` — ট্যাবের সংখ্যা নিজে থেকেই ঠিক হয়ে যাবে।

ছবি না থাকলে ইমোজি রাখতে পারেন:
```html
<div class="dish__media"><span class="dish__emoji">🍹</span></div>
```
আর ট্যাগ বসাতে চাইলে:
```html
<span class="dish__tag dish__tag--hot">🔥 জনপ্রিয়</span>     <!-- লাল -->
<span class="dish__tag dish__tag--new">✨ নতুন</span>         <!-- সবুজ -->
<span class="dish__tag dish__tag--veg">🌱 নিরামিষ</span>      <!-- হালকা সবুজ -->
```

### ঘ) আসল ছবি বসানো
1. ছবি `assets/img/` ফোল্ডারে রাখুন (নাম ইংরেজিতে রাখা ভালো, যেমন `tea_masala.jpg`)।
2. `index.html`-এ ওই কার্ডের `<img src="assets/img/....svg">` বা `dish__emoji` স্প্যানের জায়গায় লিখুন:
   ```html
   <img src="assets/img/tea_masala.jpg" alt="মসলা চা" loading="lazy" decoding="async">
   ```
3. পরামর্শ: ছবির সাইজ **৭৬০ × ৫৭০ পিক্সেল (৪:৩)**, ফাইল ১৫০ KB-এর নিচে রাখলে সাইট দ্রুত লোড হবে।

> বর্তমানে কিছু আইটেমে **ভেক্টর আর্ট** (`assets/img/*.svg`) ব্যবহার করা হয়েছে, কারণ ওই আইটেমগুলোর আসল ছবি ছিল না। আসল ছবি পেলে উপরের নিয়মে পাল্টে দিন — ডিজাইন একই থাকবে।

### ঙ) রঙ ও ফন্ট বদলানো
`styles.css`-এর একদম উপরে `:root`-এ সব রঙ এক জায়গায় আছে:
```css
--gold: #e2a33c;    /* সোনালি অ্যাকসেন্ট */
--green: #17785a;   /* সবুজ (দাম, অর্ডার বাটন) */
--brown-dark: #2a1608;  /* গাঢ় ব্রাউন (হেডার টেক্সট) */
--cream: #fff8ee;   /* ব্যাকগ্রাউন্ড */
```

### চ) ঠিকানা, খোলার সময়, ফেসবুক/ইনস্টাগ্রাম লিংক
`index.html`-এ খুঁজুন: `ধানমন্ডি ১৫` (ঠিকানা), `সকাল ৭টা` (সময়), `facebook.com` / `instagram.com` (লিংক)। এগুলো এখন ডেমো — অবশ্যই নিজের তথ্য বসাবেন।

## ৫. ইন্টারনেটে প্রকাশ করা (হোস্টিং)

- **সবচেয়ে সহজ (ফ্রি):** [Netlify Drop](https://app.netlify.com/drop) — পুরো ফোল্ডারটা ড্র্যাগ করে ছেড়ে দিন, সাথে সাথে লিংক পাবেন।
- **GitHub Pages:** GitHub-এ একটা রিপো বানিয়ে ফাইলগুলো আপলোড করুন → Settings → Pages → Branch: `main`, Folder: `/root` → Save. লিংক হবে `https://আপনার-নাম.github.io/রিপো-নাম/`।
- **নিজের ডোমেইন:** যেকোনো হোস্টিং (cPanel/হোস্টসেলার ইত্যাদি)-এ `public_html` ফোল্ডারে সব ফাইল আপলোড করে দিন। PHP/ডেটাবেসের দরকার নেই — এটা স্ট্যাটিক সাইট।

কাস্টম ডোমেইন কিনলে (যেমন `japanichaapani.com`) হোস্টিং প্যানেল থেকে পয়েন্ট করে দিন।

## ৬. ছোট নোট

- **ফন্ট:** ফন্টের ফাইল সাইটের ভেতরেই আছে (`assets/fonts/`) — ধীর ইন্টারনেটেও লেখা ঠিকভাবে দেখাবে।
- **প্রিন্ট মেনু:** সাইটটি ব্রাউজারে খুলে `Ctrl+P` চাপলে মেনু কার্ডের অংশ (ছবি, দামসহ) প্রিন্ট বা PDF করা যাবে — বাটন/নেভিগেশন প্রিন্টে আসবে না।
- **ছবি:** সাইটের সব ছবি AI দিয়ে বানানো ডেমো ছবি। নিজের দোকানের আসল ছবি বসালে বেশি বিশ্বাসযোগ্য দেখাবে — শুধু `assets/img/`-এ বদলে দিলেই হবে।
- **ভবিষ্যতে যোগ করা যায় (চাইলে):** অনলাইন পেমেন্ট (বিকাশ/নগদ), ডেলিভারি চার্জ ক্যালকুলেটর, অ্যাডমিন প্যানেল, বা অর্ডার সরাসরি ডেটাবেসে জমা। চাইলে বলুন, বানিয়ে দেব।
