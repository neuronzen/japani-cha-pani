```
  tools/make_art.py     ভেক্টর ছবিগুলো আবার তৈরি করার স্ক্রিপ্ট

README.md               এই ফাইল
```

## ৩. চালু করবেন কীভাবে

- **সহজ উপায়:** `index.html` ফাইলে ডাবল ক্লিক করুন — ব্রাউজারে সাইট খুলে যাবে।

## ৪. GitHub-এ আপলোড ও লাইভ করা (৩ ধাপ)

### ধাপ ১ — GitHub-এ খালি রিপো খুলুন
1. ব্রাউজারে [github.com/new](https://github.com/new) খুলুন (লগইন করা থাকতে হবে)।
2. **Repository name:** যেমন `japani-cha-pani` (ইংরেজিতে রাখুন)।
3. **Public** সিলেক্ট করুন (ফ্রি হোস্টিংয়ের জন্য)।
4. ❗ **"Add a README file" / .gitignore / license — কোনোটা টিক দেবেন না।**
5. **Create repository** চাপুন।

### ধাপ ২ — ফাইল আপলোড (দুটো উপায়ের যেকোনো একটা)

**উপায় ক) এক কমান্ডে (রেকমেন্ডেড — সব ফাইল, প্লাস অটো-ডিপ্লয় সেটিংসহ)**
কম্পিউটারে [Git](https://git-scm.com/downloads) ইনস্টল থাকলে প্রজেক্ট ফোল্ডারে টার্মিনাল খুলে:
```bash
bash deploy.sh https://github.com/আপনার-ইউজারনেম/japani-cha-pani.git
```
প্রথমবার চালালে GitHub লগইনের জন্য ব্রাউজার খুলবে (অথবা পাসওয়ার্ডের জায়গায় Personal Access Token চাইবে)।
ডান দিকের **Code ▾** বাটনে ঠিক যে লিংকটা দেখাবে, সেটাই কপি করে বসাবেন।

**উপায় খ) ব্রাউজার দিয়ে (কোনো সফটওয়্যার লাগবে না)**
1. নতুন রিপোর পেজে **"uploading an existing file"** লিংকে ক্লিক করুন।
2. প্রজেক্ট ফোল্ডার থেকে `index.html`, `styles.css`, `script.js`, `README.md`, `deploy.sh`, `assets` ফোল্ডার — সব ড্র্যাগ করে ছেড়ে দিন। (`.gitignore`, `.nojekyll`, `.github` ফোল্ডারগুলো লুকানো; ব্রাউজার ডায়ালগে না দেখালে বাদ দিলেও চলবে — সাইট চলবে।)
3. নিচে **Commit changes** চাপুন।

### ধাপ ৩ — সাইট লাইভ করুন (GitHub Pages)
1. রিপোর **Settings → Pages**-এ যান।
2. **Source**-এ দুটোর একটা বাছুন:
   - `deploy.sh` দিয়ে পুশ করেছেন? → **GitHub Actions** সিলেক্ট করুন। (`.github/workflows/pages.yml` প্রতিবার পুশেই নিজে নিজে ডিপ্লয় করবে।)
   - শুধু ব্রাউজার আপলোড? → **Deploy from a branch** → Branch: `main`, Folder: `/ (root)` → **Save**।
3. ১–২ মিনিট পর সাইট লাইভ:
   `https://আপনার-ইউজারনেম.github.io/japani-cha-pani/`

> **পরবর্তী আপডেট করতে:** ফাইল বদলে আবার `git add -A && git commit -m "আপডেট" && git push` (বা `bash deploy.sh <একই-লিংক>`) চালালেই সাইট নিজে আপডেট হয়ে যাবে।

### নিজের ডোমেইন (যেমন `japanichaapani.com`)
1. **Settings → Pages → Custom domain**-এ ডোমেইন লিখে Save করুন (এতে `CNAME` ফাইল তৈরি হবে)।
2. ডোমেইন কেনার জায়গায় DNS-এ এই রেকর্ডগুলো বসান:
   - `A` রেকর্ড → `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`
   - `www` নামের `CNAME` → `আপনার-ইউজারনেম.github.io`
3. DNS ঠিক হলে **Enforce HTTPS** টিক দিন।

## ৫. নিজে যেভাবে বদলাবেন

### ক) ফোন নম্বর / হোয়াটসঅ্যাপ নম্বর বদলানো
নম্বর এখন সব জায়গায় **০১৬৭৭-৭২৫৭১১** করে দেওয়া আছে। ভবিষ্যতে বদলাতে হলে:

1. **`script.js`** ফাইলের একদম উপরে:
   ```js
   var SHOP = {
     whatsapp: "8801677725711",   // ← দেশের কোড ৮৮ সহ, + ছাড়া
     currency: "৳"
   };
   ```
2. **`index.html`**-এ `1677725711` লিখে সার্চ করুন — `tel:` আর `wa.me` লিংকগুলোও একইভাবে বদলে দিন (প্রায় ৯ জায়গা: টপবার, হিরো বাটন, যোগাযোগ কার্ড, সোশ্যাল আইকন, ফুটার)।

### খ) ঠিকানা / গুগল ম্যাপ
`index.html`-এ `মীরের বাজার` লিখে খুঁজুন। ম্যাপ লিংকে `query=` এর পরের ঠিকানাটা বদলালেই ম্যাপ আপনার ঠিকানায় যাবে:
```html
https://www.google.com/maps/search/?api=1&query=Mirer+Bazar+Masjid+Road,+Pubail,+Gazipur
```
(গুগল ম্যাপে দোকানের পিন বসিয়ে "Share → Copy link" থেকে দিলে আরও নিখুঁত হবে।)

### গ) দাম বা আইটেমের নাম বদলানো
প্রতিটি কার্ড এমন:
```html
<article class="dish" data-cat="tea" data-name="মালাই চা" data-price="30">
  ...
  <span class="price">৳ ৩০ <small>/ কাপ</small></span>
```
- `data-price="30"` → কার্টের হিসাবের জন্য **আরবি সংখ্যায়**।
- `৳ ৩০` → স্ক্রিনে দেখানোর জন্য **বাংলা সংখ্যায়** (না লিখলেও চলে)।
- `data-name` + `data-price` ঠিক থাকলেই বাকি কাজ স্ক্রিপ্ট নিজে করবে।

### ঘ) নতুন আইটেম যোগ করা
যেকোনো একটি `<article class="dish" ...> ... </article>` ব্লক কপি করে নিচে বসিয়ে নাম, দাম ও ছবি বদলে দিন। `data-cat` হবে `tea`, `coffee`, `juice` বা `fastfood` — ট্যাবের সংখ্যা নিজে থেকেই আপডেট হবে। ট্যাগ বসাতে চাইলে:
```html
<span class="dish__tag dish__tag--hot">🔥 জনপ্রিয়</span>   <!-- লাল -->
<span class="dish__tag dish__tag--new">✨ নতুন</span>       <!-- সবুজ -->
<span class="dish__tag dish__tag--veg">🌱 নিরামিষ</span>    <!-- হালকা সবুজ -->
```
ছবি না থাকলে ইমোজি: `<div class="dish__media"><span class="dish__emoji">🍹</span></div>`

### ঙ) আসল ছবি বসানো (গুরুত্বপূর্ণ)
এখন ৮টি আইটেমে **AI-বানানো ফটো** আর ২১টিতে **ভেক্টর আর্ট** আছে। দোকানের আসল ছবি বসালে সবচেয়ে ভালো দেখাবে:
1. ছবি `assets/img/`-এ রাখুন (নাম ইংরেজিতে, যেমন `tea_masala.jpg`)।
2. ওই কার্ডে `<img src="assets/img/....svg">` (বা `dish__emoji` স্প্যান) বদলে লিখুন:
   ```html
   <img src="assets/img/tea_masala.jpg" alt="মসলা চা" loading="lazy" decoding="async">
   ```
3. সাইজ **৭৬০ × ৫৭০ পিক্সেল (৪:৩)**, ফাইল ১৫০ KB-এর নিচে রাখলে সাইট দ্রুত লোড হবে।

> `assets/raw/` ফোল্ডারে বড় সাইজের মূল ছবিগুলো আছে — এগুলো সাইটে ব্যবহার হয় না, শুধু পোস্টার/ফেসবুকের জন্য। এ কারণেই `.gitignore`-এ রাখা, যাতে GitHub রিপো হালকা থাকে। (আপনার কম্পিউটারে ফোল্ডারটা থাকবে, GitHub-এ যাবে না।)

### চ) রঙ ও ফন্ট বদলানো
`styles.css`-এর `:root`-এ সব রঙ এক জায়গায়:
```css
--gold: #e2a33c;        /* সোনালি অ্যাকসেন্ট */
--green: #17785a;       /* সবুজ (দাম, অর্ডার বাটন) */
--brown-dark: #2a1608;  /* গাঢ় ব্রাউন */
--cream: #fff8ee;       /* ব্যাকগ্রাউন্ড */
```

### ছ) খোলার সময়, পেমেন্ট, ফেসবুক/ইনস্টাগ্রাম লিংক
`index.html`-এ খুঁজুন: `সকাল ৭টা` (সময়), `বিকাশ` (পেমেন্ট), `facebook.com` / `instagram.com` (লিংক)।

## ৬. ছোট নোট

- **ফন্ট:** ফন্টের ফাইল সাইটের ভেতরেই আছে (`assets/fonts/`) — ধীর ইন্টারনেটেও লেখা ঠিকভাবে দেখাবে।
- **প্রিন্ট মেনু:** `Ctrl+P` চাপলে মেনু কার্ডের অংশ (ছবি, দামসহ) প্রিন্ট বা PDF হবে — বাটন/নেভিগেশন আসবে না। দোকানে টাঙানোর মেনু বোর্ড বানাতে কাজে লাগবে।
- **ছবি:** সাইটের সব ছবি AI দিয়ে বানানো ডেমো — আসল দোকানের ছবি বসালে বেশি বিশ্বাসযোগ্য হবে।
- **ভবিষ্যতে যোগ করা যায়:** অনলাইন পেমেন্ট (বিকাশ/নগদ), ডেলিভারি চার্জ ক্যালকুলেটর, অ্যাডমিন প্যানেল, জিমেইলে অর্ডার নোটিফিকেশন। চাইলে বলুন, বানিয়ে দেব।
