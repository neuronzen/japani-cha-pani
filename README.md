## ২. ফাইল স্ট্রাকচার

```
index.html              পুরো সাইটের কাঠামো ও লেখা (HTML)
styles.css              ডিজাইন — রঙ, ফন্ট, লেআউট (CSS)
script.js               মোবাইল মেনু, মেনু ফিল্টার, অ্যানিমেশন (JavaScript)
deploy.sh               এক কমান্ডে GitHub-এ পুশ করার স্ক্রিপ্ট
.github/workflows/      GitHub Pages অটো-ডিপ্লয়
assets/
  img/                  সাইটের সব ছবি
     ├ shop_front.jpg / shop_seating.jpg / shop_side.jpg     ← দোকানের আসল ছবি
     ├ menu_board*.jpg                                        ← মেনু বোর্ডের আসল ছবি
     ├ hero_tea.jpg, tea_malai.jpg, fast_burger.jpg ...       ← খাবারের ছবি
     └ *.svg                                                  ← ভেক্টর আর্ট (যেখানে আসল খাবারের ছবি নেই)
  fonts/                বাংলা ফন্ট (Noto Sans Bengali + Baloo Da 2)
  raw/                  AI-বানানো মূল ছবি (বড়; .gitignore-এ আছে — GitHub-এ যায় না)
  tools/make_art.py     SVG ছবিগুলো আবার বানানোর স্ক্রিপ্ট
  preview/              সাইটের স্ক্রিনশট
README.md               এই ফাইল
```

> **ছবি কোথা থেকে এলো?** দোকানের ছবি ও মেনু বোর্ডের ছবি **আপনার গুগল ম্যাপ প্রোফাইল** থেকে নিয়ে অপটিমাইজ করা হয়েছে।
> খাবারের কিছু ছবি এখন AI-বানানো/ভেক্টর (কারণ ওই আইটেমগুলোর আসল ছবি পাওয়া যায়নি) —
> আপনি নিজের ফোনে তোলা ছবি দিলে বদলে দেওয়া যাবে (নিচে ৫ নম্বর দেখুন)।

## ৩. চালু করা ও GitHub-এ আপডেট করা

**নিজের কম্পিউটারে চালাতে:**
```bash
python3 -m http.server 8000     # তারপর http://localhost:8000
```
অথবা শুধু `index.html` ফাইলে ডাবল ক্লিক করুন।

**GitHub-এ আপডেট করতে** — দুই উপায়:
1. **ব্রাউজার থেকে (সবচেয়ে সহজ, ফোনেও হয়):** GitHub-এ রিপো খুলুন → যে ফাইল বদলাবেন সেটায় ক্লিক → ✏️ পেনসিল → লেখা বদলান → নিচে **Commit changes**। ১ মিনিটেই সাইট লাইভ আপডেট হয়ে যাবে।
2. **কম্পিউটার থেকে:** ফাইল বদলে:
   ```bash
   bash deploy.sh https://github.com/neuronzen/japani-cha-pani.git
   ```

## ৪. নিজে যেভাবে বদলাবেন

### ক) দাম বদলানো / নতুন আইটেম যোগ করা
`index.html`-এ আইটেমের নাম দিয়ে খুঁজুন। প্রতিটি কার্ড এমন:
```html
<article class="dish" data-cat="hot">
  <div class="dish__media"><img src="assets/img/coffee_hot.svg" alt="ব্রাউন কফি" loading="lazy"></div>
  <div class="dish__body">
    <h3 class="dish__name">ব্রাউন কফি</h3>
    <p class="dish__desc">দুধ-কফির পারফেক্ট ব্যালান্স — রেগুলার বা স্পেশাল।</p>
    <div class="dish__foot"><span class="price">৳ ৮০–৯০</span></div>
  </div>
</article>
```
- `data-cat` হবে: `tea`, `hot` (হট কফি), `cold` (কোল্ড কফি/শেক), `juice`, `food` (ফাস্টফুড)।
- দাম বাংলা সংখ্যায় লিখুন (৳ ৮০–৯০)। যেখানে একাধিক দাম, সেখানে “রেগুলার / স্পেশাল” লিখে বোঝানো ভালো।
- ট্যাগ বসাতে চাইলে ছবির সাথে:
  ```html
  <span class="dish__tag dish__tag--hot">🔥 বেশি বিক্রি</span>   <!-- লাল -->
  <span class="dish__tag dish__tag--new">✨ স্পেশাল</span>       <!-- সবুজ -->
  ```

### খ) আসল ছবি বসানো (সবচেয়ে বেশি কাজে দেবে)
আইটেমে এখন যেখানে `.svg` ছবি আছে (যেমন `coffee_hot.svg`), সেখানে নিজের তোলা ছবি বসান:
1. ছবি `assets/img/` ফোল্ডারে রাখুন (ইংরেজি নাম, যেমন `brown_coffee.jpg`)।
2. ওই কার্ডে `src` বদলে দিন:
   ```html
   <img src="assets/img/brown_coffee.jpg" alt="ব্রাউন কফি" loading="lazy" decoding="async">
   ```
3. সাইজ **৭৬০×৫৭০ (৪:৩)** আর ১৫০ KB-এর নিচে রাখলে সাইট দ্রুত লোড হবে।

### গ) ফোন, ঠিকানা, সময় বদলানো
`index.html`-এ সার্চ করুন: `1677725711` (ফোন), `মীরের বাজার` (ঠিকানা), `সকাল ৭:০০` (সময়)।
নম্বর বদলালে `tel:` ও `wa.me` — দুই জায়গাতেই বদলাতে হবে (মোট ৯টি লিংক)।

### ঘ) ম্যাপের পিন
`index.html`-এ খুঁজুন `maps.google.com/maps?q=` — এর পরে `23.9284667,90.4515093` লেখা আছে।
গুগল ম্যাপে দোকানের পিনে ক্লিক করে “Share → Copy link” থেকে নিজের লোকেশন নিয়ে বদলে দিলে পিন একদম নিখুঁত হবে।

### ঙ) রঙ ও ফন্ট
`styles.css`-এর `:root`-এ সব রঙ এক জায়গায়:
```css
--gold: #e2a33c;    /* সোনালি অ্যাকসেন্ট */
--green: #17785a;   /* সবুজ (দাম) */
--brown-dark: #2a1608;
--cream: #fff8ee;   /* ব্যাকগ্রাউন্ড */
```

## ৫. ছোট নোট

- **ফন্ট:** বাংলা ফন্ট সাইটের ভেতরে আছে — ধীর ইন্টারনেটেও লেখা ঠিক দেখাবে।
- **প্রিন্ট মেনু:** ব্রাউজারে `Ctrl+P` চাপলে মেনু কার্ডগুলো (ছবি ও দামসহ) পরিষ্কারভাবে প্রিন্ট/PDF হবে — বাটন ও নেভিগেশন বাদ যাবে। দোকানে টাঙানোর জন্য কাজে দেবে।
- **গুগল ম্যাপের ছবি ব্যবহার:** দোকানের ছবি ও মেনু বোর্ডের ছবি আপনার নিজের দোকানের, তাই ব্যবহারে সমস্যা নেই। ভবিষ্যতে হয়তো ম্যাপে ছবি বদলালে সাইটে পুরোনো ছবি থাকবে — তখন নতুন ছবি দিয়ে বদলে দিতে হবে।
- **ভবিষ্যতে যোগ করা যায় (চাইলে বলুন):** গুগল ম্যাপে রিভিউ শোকেস, ফেসবুক পেজ ইন্টিগ্রেশন, অফার/কম্বোর আলাদা সেকশন, ছবি আপলোড করার সহজ ব্যবস্থা।
